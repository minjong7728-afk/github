# 하루기록

하루기록은 오늘 해야 할 목표를 작성하고 확인하는 웹페이지입니다. 공부, 운동, 생활 목표를 기록하려는 사람이 사용할 수 있습니다.

## 중간고사 추가 기능

7주차에는 목표 작성, 종류 선택, 확인, 완료하기 기능을 만들었습니다. 이번에는 **완료한 목표를 저장하고 목록에서 확인하거나 삭제하는 기능**을 추가했습니다.

## 사용 방법과 조건

1. 목표를 입력하고 종류를 선택한 뒤 목표 확인하기를 누릅니다. 값이 비어 있으면 안내 문구가 나오고 확인 버튼을 사용할 수 없습니다.
2. 목표 완료하기를 누르면 완료 화면이 나타납니다.
3. 완료한 목표 저장하기를 누르면 나의 목표 기록에 목표 내용과 종류가 추가됩니다.
4. 같은 목표를 다시 저장하려 하면 중복 저장되지 않고 안내 문구가 나타납니다.
5. 저장한 목표 옆의 삭제 버튼을 누르면 목록에서 사라지고 남은 개수가 표시됩니다. 목록이 비어 있으면 새로운 목표를 저장하라는 안내가 나옵니다.
6. 새 목표 시작하기를 누르면 작성 중인 목표는 초기화되지만 저장한 목표 목록은 유지됩니다.

## 테스트 기록

1. 목표를 입력하고 저장했을 때 목록에 정상적으로 추가됨
2. 여러 개의 목표를 저장했을 때 목록에 표시됨
3. 삭제 버튼을 누르면 해당 목표가 삭제됨
4. 저장된 목표가 없으면 안내 문구가 표시됨
5. 목표를 입력하지 않으면 오류 안내가 표시됨
6. 모바일 화면에서도 정상적으로 조작됨
